OkCupid Case Study

Bridging the Trust Gap in OkCupid’s Compatibility System

Rebuilding confidence through onboarding, transparency, and meaningful matching

Overview

OkCupid is a dating app that uses a question-based matching algorithm to help users find compatible people.

As part of a 2-week academic UX design sprint, our team explored how users understand and trust OkCupid’s matching experience.

Through research and usability testing, we found that match scores often lacked the context users needed to understand compatibility, leading us to rethink the experience.

Building the New Journey

This insight led us to redesign the journey by making onboarding more relevant, improving clarity in matching, and creating a more progressive and trustworthy experience.

Information Architecture

After gathering the insights from the research, we’ve ideated brainstormed the new IA. The goal was the make the app more trustworthy for the user & improve the onboarding experience.

​

The Redesigned Experience

A redesigned experience that makes onboarding more relevant, profiles more meaningful, and matches easier to understand.

A more organised onboarding

We restructured onboarding into clear steps so users can build their profile progressively

Eg: About Yourself grouped into one single section

Build with guidance

AI-assisted bio feature to help users quickly create stronger and more meaningful profiles.

Must Haves

Match relevance was improved by showing how many users share similar preferences and location.

A “Must Haves” section allows users to define key partner expectations early on

Intent-Based Questions

Questions adapt to what the user is looking for — long-term relationship, casual dating, friendship, etc.

More relevant questions create better matches by focusing on the user’s actual intentions

Profile Control

A final review step allows users to check and edit their profile.

Review step in which you can see how others see you and can edit everything accordingly.

The must have are now visible pinned in the profile card

Pulse Insight

It gives users a more personal sense of compatibility before they explore the full “Why this a Match?”

Added “Why this is a match” alongside the match percentage, giving the match percentage more meaning.

A More Informative Profile Card

We gave much meaning and definition to the must have and why this a match directly onto the profile card, making compatibility easier to see while browsing.

Learnings

Good design starts with understanding people. User research helped us question our assumptions, identify real patterns, and make more informed decisions. We also learned how important it is to connect different research methods, look beyond the product itself, and translate insights into simple, meaningful design changes.
